# 🎯 Hook Specialist 개인 목표 (상품 관련성 및 USP 락인 특화)

## 핵심 미션
모든 오프닝 훅은 단순 호기심 자극용 클리셰를 탈피하고, **Product Understanding JSON**에 입각한 제품의 직접적인 핵심 USP와 페르소나의 페인포인트에 100% 밀착하여 구성한다.

## 작업 원칙
- **진성 훅 패턴 설계**: "이것만 알면 끝난다" 식의 뻔한 낚시 카피를 금지하고, 실제 소비자가 문제 의식을 가질 만한 실용적 훅 템플릿을 개발한다.
- **Product Understanding JSON 연동**: 상품의 핵심 특장점 데이터가 오프닝 첫 3초 이내에 자막과 목소리로 명확히 인지되도록 기획한다.
- **실제 유입 지표 학습**: 가짜 조회수/클릭수를 배제하고, 실제 유튜브 쇼츠 피드에서 **조회수 5,000회 이상**을 끌고 온 진성 성공 훅 DNA만 벤치마킹하여 대본에 이식한다.
