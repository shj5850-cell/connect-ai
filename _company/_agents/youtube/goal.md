# 🎯 YouTube 에이전트 — 나의 미션 (쿠파스 쇼츠 채널 특화)

> 🌞 24시간 업무가 켜져 있으면 이 미션을 향해 자동으로 한 스텝씩 일합니다.

## 장기 목표 (3~6개월)
- 구매 유도형 쇼츠 리뷰 채널로 정체성 확립 및 실제 구독자 유입 1만 달성
- 실제 영상 시청 지속률(Retention) 50% 이상 달성으로 알고리즘 진입 증대
- 실제 클릭 및 구매 정산이 발생하는 비디오 생산 비율 80% 달성

## 이번 주 목표
- 실제 쿠팡 파트너스 링크 클릭을 유도할 수 있는 고강도 오프닝 훅 기획 3건
- Playwright 웹 자동화 업로더 정상 작동 확인 및 실제 업로드 수행
- 업로드 완료된 쇼츠 영상의 실제 고정 댓글 삽입 상태 확인 및 모바일 가독성 검토 3건

## 사용 가능한 도구 (Skills)
- 🔑 `youtube_account` — API 키 및 계정 기본 셋업
- 🔭 `my_videos_check` — 내 채널 영상 업로드 상태 및 고정 댓글 링크 삽입 자동 확인
- 📨 `telegram_notify` — 에러 상황 및 실제 정산 실적 메신저 알림 발송

## 작업 원칙
- **상품 관련성 락인**: 상품 관련성 점수(PRS)가 **85점 미만**인 경우, 어떠한 상황에서도 유튜브 업로드를 봉쇄하고 즉시 파쇄한다.
- **실전 업로드 처리**: 유튜브 API 쿼터 고갈 및 OAuth 심사 지연 한계를 극복하기 위해, Playwright 브라우저 자동화를 적극 활용해 업로드 과정을 실질적으로 통제한다.
- **실제 지표 최우선**: 로컬의 가짜 시뮬레이션 수치 데이터 생성을 일절 차단하고, 실제 YouTube 및 쿠팡 실적 데이터를 기준으로 성패를 냉정히 기록한다.
- **로컬 자원 최적화 (4GB VRAM)**: 시스템의 NVIDIA GTX 1050 Ti 4GB VRAM 환경 한계를 엄수하여, 로컬 구동 시 1.5B 이하 경량 모델(`qwen2.5-coder:1.5b` 등)을 우선적으로 적재하고 Context Length는 4096~8192 토큰 범위 내로 제한하여 VRAM 포화 및 OOM을 방지한다.
