# 🔍 웹 검색 및 경쟁사 데이터 수집 (web_search)

이 도구는 지정된 검색 쿼리를 바탕으로 관련 AI 자동화 솔루션 및 경쟁사 데이터를 웹에서 수집하고 분석 리포트와 CSV 파일을 생성합니다.

## 설정 인자
* `QUERY` - 검색하려는 키워드. (기본값: "AI 자동화 수익화 모델")
* `MOCK_ONLY` - 오프라인 모드 여부. (기본값: true)

## 출력 산출물
* `web_search_report.md` - 수집된 경쟁사 상세 분석 마크다운 보고서
* `sessions/competitors.csv` - AI 에이전트들이 공용으로 분석 가능한 정형 데이터 파일
