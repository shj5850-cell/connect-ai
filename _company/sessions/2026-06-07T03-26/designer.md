# 🚀 새로운 디자인 아이디어 검토 및 최적화

## 1. 수집된 데이터 분석
### 목표
- **데이터 분석**: 현재 서비스의 컨텐츠를 바탕으로 디자인 아이디어를 개발하고, 고객의 피드백을 반영해 최적화합니다.
- **전달성 극대화**: 컨텐츠의 전달성을 높이기 위해 디자인 요소들을 효율적으로 활용합니다.

### 작업 1: 데이터 수집 및 분석
- **레오**: 수집된 데이터를 읽어보고, 각 영상의 조회수, 좋아요 수, 비구조화된 텍스트 추출 등 데이터를 확인합니다.
  - 데이터 가져오는 방법:
    ```python
    import requests

    url = 'https://api.youtube.com/v3/videos'
    params = {
        'part': 'snippet,contentDetails',
        'id': 'VIDEO_ID',
        'key': YOUR_API_KEY
    }

    response = requests.get(url, params=params)
    data = response.json()
    ```

### 작업 2: 데이터 분석 및 추적
- **현빈**: 수집된 데이터를 분석하여 어떤 영상이 더 많이 조회되고 좋아요 수가 높은지 파악합니다. 이 정보를 바탕으로 디자인 아이디어를 개발하고, 고객의 피드백을 반영해 최적화합니다.
  - 예시:
    ```
    가장 인기 있는 영상: Video ID #12345
