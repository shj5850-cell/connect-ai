# 뉴스 피드 및 스크립트 수정

## 1. 뉴스 피드 작성
### 목표
- 최근 트렌드에 맞게 뉴스 피드를 수정하여 인스타그램의 팔로워 수를 올리기 위해
- 뉴스와 관련된 해시태그 사용을 강화

### 작업 1: 뉴스 소스 수집 및 정리
- **레오**: 오늘의 신뢰할 만한 뉴스 소스들을 수집하고, 최신 뉴스를 필터링합니다.
  - 추천 뉴스 사이트: [뉴스라인](https://newsline.co.kr/)
  - 데이터 수집 방법: API 또는 Web scraping

### 작업 2: 새로운 뉴스 요약 및 해시태그 생성
- **레오**: 수집된 뉴스를 간략하게 요약하고, 사용 가능한 해시태그들을 선택하여 추가합니다.
  - 예시:
    ```
    #리뷰
    #쇼핑
    #꿀템
    #신상품
    ```

### 작업 3: 인스타그램 릴스 작성 및 게시
- **레오**: 수집된 뉴스를 기반으로 뉴스 릴스를 작성하고, 적절한 해시태그와 게시 시간을 추가합니다.
  - 예제 뉴스 릴스:
    ```
    🚀 신상품 추천! 새로운 과일 브랜드의 제품이 출시되었습니다. #리뷰 #쇼핑 #꿀템
    ```

### 작업 4: 리소스 관리 및 업데이트
- **현빈**: 수집된 뉴스 데이터를 저장하고, 다음 날
